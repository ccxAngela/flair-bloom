Status: active

## 范围与授权

用户要求「合并推送，然后发版前审查，没问题就发版」，授权本次 Windows x64 应用 0.9.0 的 tag、草稿资产和检查通过后的公开发布。基线为稳定版 `v0.8.2`；官网读取公开 Release，不单独发布。
