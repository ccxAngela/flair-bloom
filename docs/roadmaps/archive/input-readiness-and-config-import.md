# 输入通道就绪检查与配置迁移

Status: completed

## 决策

- 游戏模式未就绪时回退通用，只禁止游戏模式，不锁通用模式的全局开关。
- Interception 检查运行通道、实际设备和键鼠各 10 槽的容量／编号，满额或越界要求 Windows 重启。
- 本应用的后端资源在切换与退出时释放；共享驱动清理仍走明确入口，通道占用不等于安装残留。
- 外设模式只在硬件握手确认后显示。通用模式名称保留，提示为普通软件与网页、大部分游戏无效。
- 支持衍天、极简、小叽和既有丐帮配置。对不能等价复现的行为明确提示，部分规则默认停用；千机魔盒无可核验配置，用户允许跳过。
- 仅保留独立转换实现与合成测试，不收录第三方源码、程序、真实配置或授权信息。
- 首装同意协议后邀请扫描，由用户选择；主菜单保留直接入口。README 只保留官网、仓库外链，欢迎研究解析 `.qzh`。
- 用户已授权审查修复、整理提交与推送；本轮不升版本、不推发布 tag、不发版。
