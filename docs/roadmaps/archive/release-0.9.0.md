## 验证与边界

- 全工作区测试 391 项通过、5 项真实环境测试默认忽略；另行显式运行的 SendInput 低级 hook 标记往返通过。
- 新增独立队列接收器，真实 SendInput 和 Interception 通道通过至少三轮 E→E→R 顺序、最短间隔、完整抬起和全局停止；输出被接收器吞掉，没有打入前台窗口。
- 当前非管理员会话中 DD 初始化失败，外设通道未连接，两者没有以回退通用模式冒充通过。它们的硬件实际输入、DD 同键来源识别及游戏接收保持未验证；公共调度与故障边界由确定性测试覆盖，不据此承诺驱动或游戏兼容。
- 队列接收器不读取或写入用户配置。相关日志位于系统临时目录 `flair-release-0.9.0`。
- 全 targets／features Clippy、Rust 格式、前端类型／生产构建、87 项前端回归、lint／格式、文档与驱动资源校验通过。版本同步后的应用原生 `cargo check` 和前端构建再次通过；审查后新增差异仅接收器、文档、版本和锁文件，已补审。
