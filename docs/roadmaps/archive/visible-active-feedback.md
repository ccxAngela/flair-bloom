# 激活状态动效可见度

Status: completed

## 决策与任务

- 用户确认同时增强全局启用和规则运行反馈。全局增加独立描边覆盖层，避免被页脚遮住；主面板与浮窗共用，不拦截点击。
- 卡片增加淡底、高对比描边和更明显的外圈脉冲；键帽增加持续描边、脉冲和角落亮点，浮窗亮点缩小。暂停态排除运行高亮，模式仍由实心／描边形状区分。
- 保留背景浓度和文字对比度约束，亮主色边缘改用适配后的主色文字色。减少动态效果时停用循环动画，保留描边与亮点。

## 验证与交接

- 已用生产 CSS 在独立 Chromium 预览中检查流金主题亮／暗两档，覆盖未启用、运行、暂停及浮窗；不运行真实引擎、不改用户配置。
- Chromium 减少动态模式的计算样式确认：卡片、键帽和全局边框动画均为 none，键帽保留 2px 描边，边框层 pointer-events 为 none。
- 21 套主题亮暗对比度测试和类型检查通过；前端构建、格式、lint、纯函数测试与文档校验按提交门禁完成。
- 仅本地提交，不改版本、不推送、不发版。
