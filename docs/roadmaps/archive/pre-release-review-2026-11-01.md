## 发现与修复

| 等级 | 问题与触发 | 修复 |
| --- | --- | --- |
| P1 | 规则／热键更新回调、默认另存或防抖写盘未完成时切换、导入配置，旧快照可能覆盖新文件，或最后一次编辑被丢弃 | 保存票据固定目标与代际，切换前等待校验和写入；加载不反向触发保存；后台保存只写指定文件，不重新激活或重设引擎 |
| P1 边界 | 托盘先激活新配置，随后旧配置保存失败，界面与实际引擎不一致；默认另存失败时残留不可重试的保存目标 | 托盘只发请求，由隐藏面板保存后加载；另存失败不提交引擎更新或保存票据，恢复界面后允许重试 |
| P2 | 全局停止与规则启停走不同通知任务；迟到的开启通知可能覆盖停止状态和语音 | 所有全局入口与规则通知在同一状态锁内入队，经唯一通道派发；面板／浮窗按统一事件更新开关，前端过滤停止后的旧规则语音 |
| 文档 | 未发布的 DD 与语音修复说明被写进已发布 0.7.1 的修复节 | 移回 Unreleased，已发布历史与原 tag 对齐 |
