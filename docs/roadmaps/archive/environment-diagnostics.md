# 统一环境诊断与重启提示

Status: completed

## 决策

- 单个可独立发送的 PowerShell 入口，生成一份包含显示与驱动证据的文本报告；旧名字保留转发入口，避免采集逻辑分叉。
- 默认普通用户运行，不自动提权；无法访问的项目记录错误，其余采集继续。只读环境，仅写报告。
- 关于按需采集实时状态，复制前重采集；屏幕 DPI、系统文字大小、应用缩放与 WebView 实际缩放分开记录。
- 驱动变更明确要求 Windows“重启”，快速启动下的关机再开机可能保留驱动状态。只报告快速启动配置，不修改它，也不推断上次启动类型。
