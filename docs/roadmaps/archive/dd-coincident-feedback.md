# DD 同键自停与切换语音

Status: completed

## 证据与决策

- 用户反馈 DD 同键切换按一次只产生三个字符并自停，开始和停止均没有语音。
- 本机日志显示 `DD_key` 首次调用返回 `0`；原代码撤销过滤并补发 SendInput。静态检查确认返回值来自 DeviceIoControl，负值错误哨兵在调用驱动前返回；`0` 不能证明没有产生输入，因此不重复提交，也不撤销过滤。首次日志补充系统错误码，保留诊断信息。
- 返回 `0` 视为已尝试提交，保留停止清理账本；这不等于确认驱动已成功投递。仍保留 50 ms 时间窗口过滤与同键启停的固有限制。
- 语音设置已开启；120 ms 状态轮询会漏过整段短暂启停。改为引擎在状态锁内将通知依序入队，独立任务串行发前端事件。hook 不直接操作 WebView，暂停／恢复和同组替换不重复播报。
- 一次临时 F24 截获探测未完成 SDK 初始化，已结束，未观察到注入事件；未据此宣称完成真实 DD 验证。
