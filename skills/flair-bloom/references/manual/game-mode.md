# 游戏模式与驱动

对应应用内教程 `game-mode`。目标：让用户明白为什么游戏里要用「游戏模式」、怎么装驱动、装完要做什么。

## 解决什么

「通用模式」靠系统 SendInput 注入，普通软件和网页能用，多数游戏不认。游戏里要用「游戏模式」（Interception 驱动），它装一个小驱动并以管理员运行，把按键送进游戏；装一次以后一直有效。「DD驱动」是备用通道（内置 DD SDK，无需重启，支持同键切换连发与横版键鼠图）。「外设模式」给有外设驱动的人：按键经串口发给外设驱动，由它作为真实 USB 键鼠敲出，即插即用、不要管理员。

## 步骤大纲

| #   | 目标锚点     | 讲什么                                                                                                                                 | 实操 |
| --- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | `input-mode` | 底部中间这个按钮是输入模式。通用模式只适合普通软件，游戏里通常不生效                                                                   | 无   |
| 2   | `input-mode` | 点开后选「游戏模式」：第一次会提示安装驱动，点「安装」、授权同意（黑框一闪是正常的）。只讲流程，装驱动等教程结束再做                   | 无   |
| 3   | 无           | 装完必须重启电脑，重新打开后再选一次游戏模式。把按键送进游戏需要管理员权限，之后每次打开都会先问要不要以管理员重启，同意后才是游戏模式 | 无   |
| 4   | `menu`       | 装不上、没反应、想卸载：☰ 菜单 → 诊断修复，能查管理员权限、驱动状态、内核隔离等前置条件并一键修                                       | 无   |
| 5   | 无           | 提醒：模拟按键有被反作弊检测的风险，个别反作弊会拦驱动导致进不去游戏，遇到就切回通用模式；用不用请自行权衡。DD 是备用通道，支持同键切换连发与横版，同键启停误判可用全局关闭或正常退出兜底 | 无   |

## 常见坑

- 安装、卸载、清理残留或排除设备槽问题后，请点击 Windows「开始 → 电源 → 重启」。开启快速启动时，关机再开机可能沿用内核与驱动状态，不能代替这里要求的重启；应用“以管理员重启”也只是重启应用。参见 [Microsoft 的快速启动说明](https://learn.microsoft.com/en-us/windows/win32/power/system-power-states)。
- ☰ → 诊断修复 → 导出诊断报告会在桌面生成 `flair-environment-*.txt`，包含驱动、安全策略、相关错误日志和显示环境；应用内报告还附带实际 WebView 缩放。仅采集并写报告，不执行修复。无法打开应用时，可运行独立的 `scripts/diagnose-environment.ps1`（或将同目录的 `diagnose-environment-oneclick.cmd` 一起发送后双击）；无需管理员，权限不足会记录。旧脚本名称保留为兼容入口，需与新脚本放在一起，也输出统一的文本报告。

- 教程不真的触发安装：安装要提权与重启，放在教程里做不完整，只讲到哪里点。
- 四种模式的副标题已经在选择菜单里（推荐 / 需要管理员 / 驱动待重启生效 / 外设驱动已插入），教程不重复背状态，只讲含义。
- DD 驱动的同键启停可能误判，导致连发自停或按原键停不下；可关闭全局开关或正常退出应用，停止连发并释放按键。外设模式仍与横版键鼠图互斥。
- 外设模式：只插外设驱动的原生 USB 口即可（开发板另一个 UART 口是烧录用的，插不插都不影响）；前面板口偶尔握手失败，插主板后置口。不在外设模式时，插上外设驱动或启动时它就插着，都会弹窗问要不要切过去（上次就是外设模式则启动时直接恢复）；外设模式下拔掉会提示并回退到通用模式，插回再问一次。自动识别只认乐鑫芯片的开发板，别的芯片做的外设驱动手动选一次外设模式即可。切换连发的启动 / 停止键仍不能等于连发键。媒体键不在外设驱动的键盘报文里，会改走通用通道。
- 外设驱动插着却打不出字：☰ → 诊断修复。「驱动状态」里外设驱动一行逐个列出 USB 串口认没认出来（转串口芯片的口会跳过，那是开发板的烧录口）。装过游戏模式驱动的电脑，这个驱动每类设备只有 10 个槽，拔插键盘、装卸虚拟键盘都会占槽且不归还，满了之后新插的外设驱动键盘输入会被吞、鼠标可能还能用；诊断会报「外设驱动的输入被吞」，重启电脑即恢复。
